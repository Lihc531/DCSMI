# Known gaps, execution-history clarifications, and manuscript alignment notes

## 1. Historical URTI generator remains missing; functional reconstruction is now provided
The supplied files include the final frozen URTI endpoint outputs, but the original source that generated the final GSE63990-conditioned P1 null distribution and patient-level P2 bootstrap distribution is still absent. `DCSMI_URTI_endpoint_runner_EXECUTION_v1_0.py` is only an input-binding/hash-check scaffold.

v1.4 provides three clearly labeled reconstructions under `scripts/06_URTI_validation/reconstructed/`: (1) an exact replay/audit reconstruction that reproduces all independently identifiable endpoint statistics from the supplied frozen assets within 1e-10; (2) a full functional reimplementation of the prespecified P1/P2 algorithm for use if the exact GSE63990 and patient-level inputs are recovered; and (3) a forensic partial disease-vector reconstruction. These are not historical source code.

The exact frozen GSE63990 disease input and the original patient-level expression/count matrix are not present, so the historical 10,000 P1 null values and 2,000 patient bootstrap draws cannot be independently regenerated byte-for-byte from currently supplied raw inputs.

The frozen pre-result amendment explicitly designates URTI P3 as **NOT_IDENTIFIABLE / NOT_TESTED**, because the two-group direction-agnostic `|Z|` construction gives identical observed profiles. It must not be reported as a biological negative.

## 2. Psoriasis primary disease background is GSE147339 Tier-B
The successful psoriasis endpoint execution manifest hashes the disease input to `420ee055...`, which exactly matches `GSE147339_psoriasis_vs_control_ALL_GENES.csv`. The runner also labels the disease input `Tier-B GSE147339`.

The later two-cohort GSE147339+GSE61281 construction is frozen as `SECONDARY_STRESS_TEST` because the cohorts are discordant (signed-Z Spearman approximately -0.108; direction concordance approximately 0.452). It should not be described as the executed primary disease background.

## 3. STRING RWR executed parameters
The frozen RWR implementation uses primary restart `r=0.5`, sensitivity `r=0.3` and `r=0.7`, maximum iterations `10000`, and L1 convergence tolerance `1e-12`. These values supersede older development-code settings such as 100 iterations / 1e-8.

## 4. Phase 12A directional interpretation
The Phase 12A prespecified primary alternative was lower-tail (more convergence). That primary lower-tail hypothesis was not supported. The observed target GJSD instead lies in the **upper tail**, which is an opposite-direction structural departure showing residual differentiation above the degree-preserving null. The manuscript can report this residual differentiation, but it should not be described as the originally prespecified lower-tail primary alternative.

## 5. Cross-layer hidden dependency recovered
The original information-compression script reads GO/KEGG term-eligibility audit files from its output directory even though those audits are generated by the separate functional-characterization analysis. The GitHub portable adapter in the companion repository explicitly reads the eligibility audits from the functional-analysis reference directory instead. The original executed script is preserved unchanged in this archive.

## 6. Target-projection input recovery check
The newly supplied `HERB_TARGET_LONG_TABLE.xlsx` plus frozen syndrome-herb weights reproduce the frozen target-projection outputs. A clean rerun produced identical values (within 1e-12) for the projection summary, frozen LOPO target weights, canonical herb-target pairs, and target-ubiquity table.

## 7. Exact historical environment
The supplied materials do not contain a complete lockfile of the original Python/R package environment. The GitHub package therefore provides a portable environment specification, clearly labeled as a reconstruction rather than the historical execution environment.
