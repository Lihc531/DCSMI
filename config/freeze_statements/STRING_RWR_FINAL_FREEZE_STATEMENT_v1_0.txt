ROLE DECISION
-------------
The frozen non-diffused LOPO ubiquity-corrected target profile remains the
PRIMARY syndrome molecular representation.

STRING RWR r=0.5 is frozen only as a SECONDARY network-localization /
sensitivity representation. It must not replace the primary target profile
for claims of syndrome differentiation.

RWR positive/nonzero target-set overlap is not a valid differentiation metric,
because diffusion makes every node in the seeded giant component positive.

DOWNSTREAM POLICY
-----------------
1. Do not tune r, STRING threshold, edge weighting, or seed construction using
   CAP results.
2. Report r=0.3 and r=0.7 only as predeclared sensitivity analyses.
3. Compare raw/frozen target-space alignment with RWR-based network-localized
   alignment as an ablation/sensitivity analysis.
4. Matched-null testing is performed only after the disease-alignment statistic
   is frozen, using the same statistic for observed and null data.
5. Later nulls should preserve seed-set size and weight distribution and match
   network degree plus target-database ubiquity.
6. Any future change to the above requires a new version and must not overwrite
   v1.0.
